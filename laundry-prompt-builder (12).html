Промпт для стирки

Готовый запрос для ИИ — редактируй, копируй, добавляй вещи полями ниже.
Текст запроса
«Просмотр» — красиво оформленный текст для чтения. «Исходный текст» — для правок. «Список вещей» — твой гардероб для стирки, хранится всегда.
Готово ✓
🔍 Фильтры
Клик по варианту — показать только его. Ещё клик — исключить (НЕ). Третий клик — сбросить. Можно сочетать несколько фильтров сразу.
Скопировано ✓
Добавить вещь в запрос
Заполни поля и нажми «Добавить» — строка впишется в раздел «Мои вещи» в запросе выше и сохранится во вкладке «Список вещей». Если нужного варианта нет в списке — выбери «Свой вариант…» и впиши его сам.
Добавлено ✓
⚠️ Опасная зона

Сохранить текущий текст запроса как новый шаблон по умолчанию. Именно к нему будет возвращать кнопка «Сбросить к шаблону» на этой странице впредь. Обычно это не нужно — используй только если осознанно хочешь поменять шаблон.
